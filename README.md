This project is a simple Flutter mobile application created as part of the Week 5 assignment. The goal was to build a basic user interface using Flutter widgets.

Features

App bar with a title

Centered column layout

Text widget displaying a welcome message

ElevatedButton that prints a message to the console when clicked

Image loaded from the internet

Basic alignment and spacing using Flutter widgets

How to Run

Install Flutter and set up your environment.

Clone this repository.

Open the project in VS Code or Android Studio.
paste the code in lib/main.dart
then

Run the app on an emulator or a physical device using the command: flutter run
